descricao: Tabela comparativa objetiva entre dois ou mais produtos

---

Monte um comparativo objetivo entre os produtos informados.

**Tabela**, com uma linha por critério e uma coluna por produto:

| Critério | Produto A | Produto B |
|---|---|---|
| Emissor | | |
| Indexador / taxa | | |
| Vencimento | | |
| Liquidez / carência | | |
| Tributação (PF) | | |
| Garantia (FGC ou não) | | |
| Risco principal | | |
| Valor mínimo | | |

Regras:

- Só preencha o que você **sabe**. Campo sem informação vira `—` e entra numa lista
  "Falta confirmar" no fim. Taxa inventada em comparativo é o erro mais caro possível.
- Se os produtos tiverem tributação diferente (ex.: CDB vs LCI), acrescente uma linha
  de **rendimento líquido equivalente** e mostre a conta. Deixe explícita a premissa
  (prazo e alíquota usados).
- Depois da tabela, um parágrafo curto: **em que situação cada um costuma ser
  apresentado**, conforme a base da casa. Isso é característica de produto, não
  indicação para pessoa.

**Limite de compliance**: nunca eleja um vencedor, nem diga "o melhor", "mais
vantajoso" ou "eu ficaria com". O comparativo termina nos fatos; a escolha é do cliente.
